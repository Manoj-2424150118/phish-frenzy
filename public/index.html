📖 How to play — the whole game, no explanation needed

  • Goal: score the most points. Highest score when the game ends wins. 🏆
  • A game is 10 questions. Every question has 4 options and a 25-second timer. Everyone answers the same question at the same time.
  • Tap once — your answer locks in and can't be changed. You instantly see if you were right, why, and your points.
  • Scoring: 100 pts for a correct answer + up to 100 speed bonus (faster = more) + 25 pts streak bonus when you hit 3 correct in a row (that's the 🔥 next to a name).
  • The round ends when everyone has answered or time runs out. After question 10, the final podium shows the winner.
  • 👑 = the host (the person who created the room). Only the host can press Start and Play Again. Up to 12 players per room. Joining mid-game makes you a spectator for that game — you play from the next one.
  • 🔑 Room codes: a code is the key to one room. It stays valid while your group is playing and is deleted only after the game finishes and everyone has left. Anyone with the code can join, so share it only with your group.
  • Dropped connection? Rejoin the same room with the same name and you reclaim your seat and score.
